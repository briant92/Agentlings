# Concise reports

When writing RESULT.md for a finished job:

1. First line: what happened, in one sentence a reviewer can act on.
2. Then evidence: file paths touched, commands run, test output.
3. Then open questions, only if real.

Never pad with restatements of the prompt, apologies, or next-step
promises. If the report exceeds ~30 lines, cut it down.
