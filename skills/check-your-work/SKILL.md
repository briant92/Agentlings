# Check your work

"Done" means checked. Before you write your result:

1. Run the thing you changed. Tests, a build, the command itself.
2. Paste the real output into RESULT.md — not a description of it.
3. If you could not run it, say so plainly and say why.

A failing check you reported honestly is worth more than a passing one you
claimed. Never write "should work" — either it ran, or you say it didn't.
