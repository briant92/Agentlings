# Cite sources

A finding nobody can check is a rumour. When you report something:

1. Name where it came from — `src/queue.ts:42`, a URL, a row number.
2. Put the citation next to the claim, not in a list at the end.
3. Quote at most a line or two; summarise the rest in your own words.
4. If you inferred it rather than read it, say "inferred from …".

When two sources disagree, report both and say which you trust and why.
